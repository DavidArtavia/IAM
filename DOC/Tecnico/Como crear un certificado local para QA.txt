Para crear un certificado de seguridad que firme las peticiones se debe realizar lo siguiente.

Paso 1 Abrir un power shell con permisos de Administrador

Paso 2 ejecutar el siguiente comando 

# ①  Crear una CA raíz (sólo una vez)
$root = New-SelfSignedCertificate `
  -DnsName "QA-Demo Root CA" `
  -KeyUsage CertSign,CRLSign,DigitalSignature `
  -FriendlyName "QA-Root-CA" `
  -KeyLength 4096 `
  -CertStoreLocation "cert:\LocalMachine\My" `
  -NotAfter (Get-Date).AddYears(10)            # 10 años

# ②  Crear el certificado del API, firmado por la CA
$apiCert = New-SelfSignedCertificate `
  -DnsName "192.168.100.157","qa-api.local" `
  -FriendlyName "QA-API" `
  -Signer $root `
  -CertStoreLocation "cert:\LocalMachine\My" `
  -TextExtension @("2.5.29.37={text}1.3.6.1.5.5.7.3.1") # ServerAuth

Paso 3 ejecutar este comando 

New-Item -Path 'C:\temp' -ItemType Directory -Force   # crea si no existe

Export-Certificate -Cert $root -FilePath 'C:\temp\qa-root.cer'


Paso 4 verificar que el certificado salió bien con el siguiente comando 
Get-Item 'C:\temp\qa-root.cer' | Format-List Name, Length

Paso 5

Site (API) ▸ Bindings… ▸ https : 8443
– Edit… → SSL certificate = QA-API → OK.

Paso 6

Stop / Start el sitio (o iisreset /restart).


NOTA: Si aún no sirve se debe instalar el certificado danto doble clic sobre el certificado
