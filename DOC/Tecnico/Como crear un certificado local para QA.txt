1) Abrir consola de PowerShell con permisos de administrador y ejecutar el siguiente comando 

# PowerShell (Admin)
$root = New-SelfSignedCertificate `
  -DnsName "QA-LOCAL-RootCA" `
  -FriendlyName "QA-LOCAL-RootCA" `
  -KeyLength 4096 `
  -KeyUsage CertSign,CRLSign,DigitalSignature `
  -CertStoreLocation "cert:\LocalMachine\My" `
  -NotAfter (Get-Date).AddYears(15)

  
2) Ejecutar el siguiente comando para exportar la parte pública del CA
 
 Export-Certificate -Cert $root `
                   -FilePath "$env:TEMP\qa-root.cer"

3) Ejecutar el siguiente comando para exportar para Chrome el certificado

certutil -addstore root "$env:TEMP\qa-root.cer"

4) Ejecutar el siguiente comando para instalar el certificado del lado del servidor

$apiCert = New-SelfSignedCertificate `
  -DnsName "192.168.100.157","qa-api.local" `
  -FriendlyName "QA-API" `
  -Signer $root `
  -CertStoreLocation "cert:\LocalMachine\My" `
  -TextExtension @("2.5.29.37={text}1.3.6.1.5.5.7.3.1") `
  -NotAfter (Get-Date).AddYears(2)

5) Ejecutar el siguiente comando para exportar el certificado al IIS y asignar una contraseña de QA

$securePwd = ConvertTo-SecureString `
  -String "MiPfxPassword123!" `
  -AsPlainText -Force

Export-PfxCertificate `
  -Cert     $apiCert `
  -FilePath "$env:TEMP\QA-API.pfx" `
  -Password $securePwd



6)

Exportar el PFX con clave privada y cadena completa

Abre mmc.exe → Añade el snap-in Certificados (Equipo local → Personal → Certificados).

Haz click derecho sobre el cert con Subject = 192.168.100.157 → Todas las tareas → Exportar…

En el asistente:

Sí, exportar la clave privada

Formato PFX

Marca “Incluir todos los certificados en la ruta de certificación”

Marca “Exportar todas las propiedades extendidas”

No marques “Eliminar la clave privada”

Pon una contraseña segura (no vacía)

Guarda, p.ej. en C:\temp\QA-API.pfx.


7) Instalar en el IIS 

IIS Manager → Server Certificates → Import…

File name: %TEMP%\QA-API.pfx

Password: deja en blanco.

Ve a Sites ▸ TuSitioAPI ▸ Bindings… → https → Edit…

Asigna SSL certificate = QA-API.

Stop / Start el sitio o ejecuta iisreset.
